## Future SQL handoff

Before any future SQL change is applied locally, its owner must hand off the reviewed file path, coordinated migration number (or explicit non-migration artifact type), source commit, parent/dependency order, intended target and preflight conditions, exact application steps, and available verifier instructions. Record each developer's installation evidence separately with the observed date and source revision when known; use **UNKNOWN** for missing values. Identify whether setup was a fresh disposable assembly or an incremental development application. After Git synchronization, each developer applies integrated SQL separately to their own local database. Git fetch/merge does not execute SQL. Preserve existing data; do not rerun earlier migrations or use the foundation-only runner for later modules.
